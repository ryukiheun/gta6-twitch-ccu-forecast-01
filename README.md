Forecasts GTA VI's launch-day Twitch viewers hour by hour from the first hour's count. For hours 2–24 it predicts five quantiles (5/25/50/75/95%) of concurrent viewers, fitted on the release-day shapes of past big launches: each launch's later hours are expressed as log ratios to its own first hour, regressed on the size of that first hour, with a spread taken from launches of a similar size. Standard library only, offline, deterministic — two runs on the same case write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
